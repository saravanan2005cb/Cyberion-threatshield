# Cyberion ThreatShield - Threat Hunting & Detection Engineering

## 📌 Project Overview
This project focuses on threat hunting, log analysis, and security detection engineering using Splunk Enterprise and simulated telemetry. It demonstrates structured security operations, including data dictionary creation, Sigma rule development, MITRE ATT&CK framework mapping, and threat hunt reporting.

---

## 🛠️ Project Components & Documentation
The repository contains the following structured documentation and files:
* **Data Dictionary:** Defines key log fields and telemetry sources.
* **Sigma Rules:** Custom detection rules for identifying suspicious activities (`sigma_rules_part1.yml`, `sigma_rules_part2.yml`).
* **MITRE ATT&CK Matrix:** Mapping threats to specific tactics and techniques.
* **Incident Response & Playbooks:** Structured workflows for handling security alerts and case reports.
* **Threat Hunt Reporting:** Comprehensive analysis of simulated security incidents.

---

## 📊 Splunk Implementation & Outputs
* **Data Ingestion & Log Analysis:** Verified security logs and engineered SPL queries.
* **Detection & Dashboards:** Built statistical summaries and visualization charts to monitor enterprise assets.
